# Zelink: Zelda & Link Mod for BG2, BG2EE, and EET
![image](https://github.com/Endarire/Zelink-Zelda-Link-Mod-for-BG2/assets/10439725/d182ee3e-63cd-477e-a4a2-886d49456b9e)

Smiling Imp's recruitable Zelda &amp; Link mod for BGII, BG2EE, and EET.  Rescued from TeamBG.com's file storage area after its forum went down in 2022.  Updated with EE/EET compatibility by Austin.

Preserved on GitHub for posterity.  Bug fixed by Claude.

**1.4's Changes**
- Seemingly every bug fixed.
- Every icon has a proper sepia sketch now.
- Walkthrough included.
- Much more playable.  Alleluia!

**1.2's Changes**
- Monsters the mod places in Irenicus's dungeon start neutral and turn hostile when they see the party, so they no longer block resting from behind walls
- Fixed the Umar Hills invasion spawning a creature that does not exist (ICG0B02 instead of ICGOB02)
- Removed corrupted item entries from several creature files
- Corrected about 150 spelling errors and doubled words in the game text and this readme
- Full English spelling and grammar pass over all game text (about 620 more corrections), plus three lines that showed the wrong text: Zelda said "IMOEN2J" instead of Imoen saying "Yeah Zelda?", and two characters (Sahasrahla's history lesson and one of Ganon's minions) showed a different, out-of-place line to female player characters
- EE: small dialogue portraits are now 54x84
- The installer now also works on macOS and Linux (lower-case file names, forward slashes)
